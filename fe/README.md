# Overwatch Insight Frontend v0.4.1

## 이번 버전
- 리플레이 분류 기준 개선: 화면 전체 하단이 아니라 고정된 우측 하단 리플레이 컨트롤 영역을 비교
- 스크린샷 폴더 자동 읽기
- 새 파일만 분류
- 요약 화면 기준 경기 자동 묶음
- 요약 / 팀 / 개인 / 리플레이 / 미분류 판별
- 경기별 검수 화면
- 이미지 화면 종류 직접 수정
- 이미지 제외 / 복원
- 이미지 순서 변경
- 이미지 수동 추가
- 검수 조건 확인
- `ready_to_upload` manifest를 브라우저 localStorage에 저장

## 아직 연결하지 않은 기능
- Supabase 실제 업로드
- OCR
- OCR 결과 검수
- DB 최종 저장

## 실행
`START_OVERWATCH.bat`을 더블클릭합니다.

기본 주소:
`http://localhost:3040/matches/new`

Windows Chrome 또는 Edge 사용을 권장합니다.
